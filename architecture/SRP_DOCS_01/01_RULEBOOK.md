# SRP — подробная книга правил

**Версия:** 0.1.0 · **Покрытие:** урок 01 · **Первоисточник:** `abstract/01.md` из пользовательского архива `abstract.zip`. Конспект является **аналитической реконструкцией**, а не оригинальным кодом AO ZOTIK и не полной стенограммой. Везде ниже «подтверждено уроком» означает подтверждено *этим конспектом*.

## Правила проверки

- `SOURCE_SUPPORTED`: текст конспекта прямо поддерживает концепцию.
- `ENGINEERING_PROPOSAL`: предлагаемый формальный контракт (не авторское утверждение).
- `UNRESOLVED`: нет информации для однозначного правила.
- `MCP_REVIEW: NOT RUN`: независимый внешний аудит не выполнен; нельзя писать PASS.
- `IMPLEMENTATION: NOT TESTED`: код и эксплуатационные тесты не исследовались.
- Слово `PASS` допустимо для проверки непротиворечивости **локального описания**, но не означает подтверждение автора, математических формул или результатов торговли.

## SRP-R001 — SP / сигнальная полоса

**Источник:** урок 01, разделы 2, 6, 10. **Статус:** SOURCE_SUPPORTED / PARTIAL.

**Буквально:** СП характеризует относительно устойчивое направление тренда; описана как соотношение EMA 21 и EMA 55; нулевая линия различает направления. Это не самостоятельный торговый сигнал.

**Вход:** значение `SP(t)` для выбранного таймфрейма. **Выход:** числовое значение СП для других правил.

**UNRESOLVED:** точная формула вычисления (включая порядок вычитания/нормировку), входная цена свечи, инициализация, версия AO ZOTIK, порядок обработки баров. Инженерная система **не должна** считать разность EMA(21)-EMA(55) окончательной формулой без исходного кода.

## SRP-R002 — OL / основная линия

**Источник:** урок 01, разделы 3, 5, 6, 10. **Статус:** SOURCE_SUPPORTED / PARTIAL.

**Буквально:** ОЛ описана через соотношение SMA 3 и SMA 34; относительно быстрее СП; взаимное положение с СП определяет волну. ОЛ также используется для распознавания локальных выступов подволн.

**UNRESOLVED:** точная формула, масштаб/нормировка, цена, порядок вычисления и условия сопоставимости шкал OL/SP.

## SRP-R003 — TrendDirection

**Источник:** урок 01, разделы 2, 8. **Статус:** SOURCE_SUPPORTED для строгих знаков; UNRESOLVED для нуля.

**Определение:** при `SP > 0` — восходящий тренд; при `SP < 0` — нисходящий тренд. `SP = 0` — отдельная **инженерная метка UNDEFINED**, пока не получено авторское правило.

**Контракт (инженерный, черновик):**

```text
trend(SP) = UP          если SP > 0
          = DOWN        если SP < 0
          = UNDEFINED   если SP = 0  [НЕ АВТОРСКАЯ ФОРМУЛИРОВКА]
```

**Граница:** возможность допуска эпсилон-зоны, точность чисел, закрытый/текущий бар — UNRESOLVED. **Запрет:** не считать `UP` командой BUY.

## SRP-R004 — WaveDirection

**Источник:** урок 01, разделы 3, 5, 8. **Статус:** SOURCE_SUPPORTED для строгих сравнений; UNRESOLVED при равенстве.

**Определение:** `OL > SP` — восходящая волна; `OL < SP` — нисходящая волна. Равенство — инженерная метка `UNDEFINED`, не вывод из авторского правила.

```text
wave(OL,SP) = UP          если OL > SP
            = DOWN        если OL < SP
            = UNDEFINED   если OL = SP [ПРЕДЛОЖЕНИЕ]
```

**Граница:** особенности пересечения и подтверждения — UNRESOLVED. **Запрет:** не считать смену волны входом в позицию.

## SRP-R005 — WaveType

**Источник:** урок 01, раздел 4. **Статус:** SOURCE_SUPPORTED, если оба направления определены.

**Определение:** волна по направлению тренда — трендовая; волна против направления тренда — коррекционная. Это **структурная роль**, не оценка силы или торговой прибыльности.

| Trend | Wave | Type |
|---|---|---|
| UP | UP | TREND_WAVE |
| UP | DOWN | CORRECTION |
| DOWN | DOWN | TREND_WAVE |
| DOWN | UP | CORRECTION |
| UNDEFINED | любое | UNDEFINED (инженерное) |
| любое | UNDEFINED | UNDEFINED (инженерное) |

**Зависимости:** R003 и R004. **UNRESOLVED:** роли возле границ и при изменениях внутри незакрытого бара.

## SRP-R006 — TrendChanged

**Источник:** урок 01, разделы 2, 8, 10. **Статус:** концепция SOURCE_SUPPORTED; алгоритм события UNRESOLVED.

**Буквально:** классификация тренда меняется при пересечении СП нулевой линии.

**Инженерная кандидатная формула, НЕ утверждённая:** событие `DOWN→UP` при переходе `SP(previous)<0` к `SP(current)>0`, и `UP→DOWN` наоборот. Прямой переход через точное значение 0, количество подтверждающих баров, повторные события, источник предыдущего состояния и бар фиксации — UNRESOLVED. Без определения этих случаев событие нельзя считать полностью специфицированным.

**Зависимость:** R003 + история подтверждённых состояний. **Торговый приказ:** отсутствует.

## SRP-R007 — WaveChanged

**Источник:** урок 01, разделы 3, 5, 8. **Статус:** концепция SOURCE_SUPPORTED; алгоритм события UNRESOLVED.

**Буквально:** при смене взаимного положения ОЛ и СП меняется направление волны.

**Инженерная кандидатная формула, НЕ утверждённая:** `DOWN→UP`, если `OL-SP` меняется с отрицательного на положительное; обратное для `UP→DOWN`. Касание, равенство, фильтрация ложных пересечений, подтверждение бара — UNRESOLVED.

**Зависимость:** R004 + история подтверждённых состояний. **Торговый приказ:** отсутствует.

## SRP-R008 — SubwaveState

**Источник:** урок 01, разделы 5, 10. **Статус:** SOURCE_SUPPORTED (различие сущностей); UNRESOLVED (детектор).

**Буквально:** подволна — отдельный локальный выступ ОЛ, а не просто смена направленности всей волны. Упоминается параметр 3 вместо 5 исходного осциллятора Вильямса.

**UNRESOLVED:** точное определение выступа, минимальная амплитуда/длительность, отношение к экстремумам, лаг обнаружения, момент подтверждения, возможность перерисовки. Не кодировать эвристику в качестве авторского правила.

## SRP-R009 — MarketStateSnapshot

**Источник:** урок 01, раздел 9. **Статус:** ENGINEERING_PROPOSAL / PARTIAL.

**Цель:** объединить результаты R003–R008 в единую запись без дублирования вычислений.

**Предлагаемые поля:** `symbol`, `timeframe`, `confirmed_bar_time`, `trend_direction`, `wave_direction`, `wave_type`, `trend_changed`, `wave_changed`, `subwave_state`, `confirmation_status`, `quality_status`.

**Инварианты:** (а) `wave_type` вычисляется из направлений, а не назначается независимо; (б) `changed` не создаёт отдельного рыночного направления; (в) неподтверждённые события не выдаются за подтверждённые; (г) из Snapshot **не следует BUY/SELL**.

**UNRESOLVED:** нормативные наборы значений quality/confirmation, полная семантика подволны и тайминга.

| Проверка | Результат | Обоснование |

## Реестр открытых вопросов

`U01`: полные формулы ОЛ и СП; `U02`: исходная цена свечи; `U03`: подтверждение пересечений на закрытом баре; `U04`: близость/равенство СП нулю; `U05`: точный критерий локального выступа ОЛ; `U06`: пересмотр ранее отмеченных волн; `U07`: значение пересечения ОЛ собственной нулевой линии (отложено автором); `U08`: равенство OL и SP и события перехода через равенство.

## Контроль по следующему уроку

При каждом новом уроке: найти совпадающие семантические определения; сослаться на существующий `SRP-Rxxx` вместо создания копии; проверить полноту таблиц и переходов; зафиксировать новые неопределённости и возможные противоречия. Повторное независимое MCP-рецензирование проводить только при фактическом подключении проверяющего и сохранять его отчёт, а не предполагать результат.
