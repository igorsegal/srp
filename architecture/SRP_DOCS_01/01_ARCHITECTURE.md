# SRP — архитектура торговой логики

**Версия:** 0.1.0  
**Срез:** урок 01 из `abstract/01.md` (аналитическая реконструкция, версия 1.0)  
**Область:** исключительно логика рыночных состояний и последующих торговых решений. Данные, инфраструктура, CMake и торговое исполнение вне текущего этапа.

## Принципы

1. Архитектура накопительная: следующий урок расширяет существующее дерево.
2. Одно правило — один нормативный идентификатор в `01_RULEBOOK.md`; здесь только ссылки.
3. Подтверждённое положение урока ≠ инженерная трактовка ≠ проверенная реализация.
4. Неразрешённые условия не заполняются догадками. Конфликтующие правила требуют записи в журнале.
5. Торговый сигнал не появляется автоматически из смены тренда либо волны.

## Дерево SRP, слой L01

```text
SRP / Торговые решения
└─ MarketState (урок 01; концептуальная модель)
   ├─ Indicators (контекст определений, формулы НЕ подтверждены)
   │  ├─ SP — сигнальная полоса [SRP-R001]
   │  └─ OL — основная линия [SRP-R002]
   ├─ TrendDirection — направление тренда [SRP-R003]
   ├─ WaveDirection — направление волны [SRP-R004]
   ├─ WaveType — трендовая/коррекционная [SRP-R005]
   ├─ TrendChanged — событие смены тренда [SRP-R006]
   ├─ WaveChanged — событие смены волны [SRP-R007]
   ├─ Subwave — меньший масштаб, локальный выступ OL [SRP-R008]
   └─ MarketStateSnapshot — связанное описание состояния [SRP-R009]
      └─ TradingDecision — ЗАРЕЗЕРВИРОВАНО, урок 01 НЕ определяет BUY/SELL
```

## Основные комбинации при ненулевых и неравных значениях

| SP | OL относительно SP | Тренд | Волна | Предварительная функция волны |
|---|---|---|---|---|
| > 0 | OL > SP | вверх | вверх | трендовая |
| > 0 | OL < SP | вверх | вниз | коррекционная |
| < 0 | OL < SP | вниз | вниз | трендовая |
| < 0 | OL > SP | вниз | вверх | коррекционная |

Таблица — формализация описанных в уроке направлений. Точные граничные условия — `UNRESOLVED` (см. `01_RULEBOOK.md`). Слова «импульсная» и «трендовая» здесь не приравниваются к подтверждённому торговому импульсу с входом.

## Контракты зависимостей

`SP → TrendDirection`; `(OL, SP) → WaveDirection`; `(TrendDirection, WaveDirection) → WaveType`; `(предыдущее, текущее подтверждённые состояния) → Changed` (требует формализации); `Subwave` — отдельная сущность и **не синоним WaveDirection**. `MarketStateSnapshot` объединяет результаты, не создавая новые определения.

## Статус L01

- **PASS (концепция):** различие тренд/волна/подволна; четыре сочетания; торговый приказ отсутствует.
- **PARTIAL (формализация):** формулы, равенства, подтверждение пересечений, правила подволн.
- **NOT TESTED:** независимая MCP-проверка, C++ реализация и тесты; ничего не объявлено готовым к торговле.
