# SRP — журнал развития архитектуры

## Правила ведения

- Каждое изменение добавляется новой записью; прошлые записи не переписываются молча.
- Идентификатор `SRP-Rnnn` постоянен. Переименование сопровождается ссылками на прежнее название.
- Для каждого урока отмечаем `ADDED / REFINED / CONFLICT / DEPRECATED`, источник и статус проверки.
- Концептуальный PASS не означает реализованную и проверенную торговую стратегию.
