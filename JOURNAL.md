# Журнал действий проекта AHexaTrader / SRP
## [2026-10-08 — 2026-10-10] Сборка C++ ядра и интеграция с MT4
### 1. Архитектура и модули
- **Гибридная структура**: C++ ядро (`PortfolioCore.dll`) + MQL4 советник.
- **Модули**:
  - `RiskManager`: расчет динамического лота (`GetTargetLotSize`) и защита маржи (`CheckMarginShieldLevel`).
  - `WPR_VSmark` и `AO_Zotik`: индикаторы Williams %R и Awesome Oscillator.
  - `WaveABC`: детектор паттернов ABC по экстремумам свечей.
### 2. Исправленные технические проблемы
- **Соглашение о вызовах**: Экспортируемые функции зафиксированы с модификатором `__stdcall` для предотвращения падения терминала MT4 из-за дисбаланса стека.
- **Сборка CMake и MSVC**: Устранена ошибка отсутствия заголовка `WaveABC.h` (C1083) путем физического создания файла и полной перегенерации кэша CMake под Visual Studio 2026.
- **Статическая линковка**: Настроен флаг `/MT` для независимости DLL от установленных библиотек Visual C++ Redistributable на торговом VPS.
### 3. Результаты
- `PortfolioCore.dll` успешно скомпилирована в конфигурации `Release`.
- Библиотека скопирована в `MQL4\Libraries\`.
- Изменения зафиксированы в Git.
- Выполнено резервное копирование на Google Диск.
