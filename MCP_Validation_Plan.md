\# Спецификация структуры проекта для валидации через MCP (Model Context Protocol)

\*Проект: SRP / АО Зотик. Назначение: Подготовка файлов для автоматической проверки логики ИИ-агентом через MCP.\*



\## 1. Что такое MCP и как он поможет?

MCP (Model Context Protocol) позволяет ИИ-агенту (например, Claude Desktop, Cursor или специализированному агенту) получить доступ к папке проекта.

Вместо того чтобы читать файлы вручную, агент:

1\. Проиндексирует все документы.

2\. Построит граф зависимостей (например, «Правило пробоя» из ТЗ связано с «Filter\_Buffer» в C++ спецификации).

3\. Найдет противоречия (например, в ТЗ написано «уровни 80/20», а в C++ коде «-80/-20» — это разные знаки).

4\. Проверит, все ли модули из ТЗ (11 пунктов ТСВ) описаны в интерфейсах.



\## 2. Структура папок для MCP-сервера
